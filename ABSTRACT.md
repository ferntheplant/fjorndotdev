# Abstract

fjorndotdev is the source of [fjorn.dev](https://fjorn.dev), Fern Sanchez's personal website. The site has a home page, blog posts, and the /good page, a list of good links: articles, books, videos, and code that Fern recommends. The site is static: every page is built ahead of time, and the site has no server code, accounts, or comments. It is not a blog engine or a template for other people's sites.
